# Edo to Now

Public site for the Edo to Now TikTok channel and its private upload tool, Edo to Now Studio.
Served by GitHub Pages at https://sadurshanoff.github.io/edotonow/

- `index.html`: about the channel and the tool (TikTok app "website URL")
- `privacy.html`, `terms.html`: privacy policy and terms of service required by TikTok's developer app
- `callback.html`: OAuth redirect page; shows the one-time code to paste into the tiktok-connect workflow.
  The code never leaves the browser.

The pipeline itself lives in the private TikTok-Automated repo.
